# Brag Plan: Meridian

## What is this app?
Meridian is an enterprise-grade, reproducible LLM benchmarking and comparative positioning platform featuring 7-axis capability radar profiling, atomic claim hallucination tracking, and industry percentile tiering running entirely on a zero-cost free-tier stack.

## The angle
Most leaderboards collapse complex models into a single misleading average score that hides critical weaknesses. Meridian reveals where a model actually stands against industry frontier baselines (GPT-4o, Claude 3.5 Sonnet) across 7 capability axes, while dissecting hallucinations at the atomic sentence claim level.

## Hook (first 2-3 seconds)
"Average leaderboard scores hide critical weaknesses. Meridian doesn't."
Fast typography with an elegant high-contrast split comparing a crude flattened "74% Average" score against Meridian's multidimensional positioning.

## Key moments (the middle)
- **Zero-Cost Benchmark Matrix (Scene 2)**: Real multi-model execution across Cloudflare Workers AI, Groq LPU, and Google AI Studio running 7 capability suites on a $0 stack.
- **7-Axis Capability Radar (Scene 3)**: Interactive geometric radar polygon comparing Candidate Model vs Industry Frontier Baseline, classifying capabilities into Frontier (92nd percentile Math) and Strong (86th percentile Coding).
- **Dual-Stage Hallucination Scorer (Scene 4)**: Atomic claim linguistic extraction highlighting exact fabricated text ("40-metre setback") with factual evidence audit cards and groundedness scoring.

## Outro / punchline
"Stop guessing model performance. Know their exact coordinates."
Meridian logomark with editorial typography, free-tier badge, and one-click launch command (`.\run.ps1`).

## User flow worth showing
1. **Entry**: Select target models (Llama 3.1, Groq Qwen, Gemini) and 7 capability suites.
2. **Key Action**: Real-time evaluation matrix streaming multi-model latency, exact match, and token F1.
3. **Result**: 7-axis radar chart with industry baseline comparison + atomic claim hallucination audit.
